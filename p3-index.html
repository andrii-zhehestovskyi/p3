P3 · LLM and AI agent robustness testing

Can the chatbot or agent be tricked into leaking data or misusing its tools — and does each fix hold?

A threat model and red-team test suite for the P2 chatbot and a simple tool-using agent. Each finding gets a severity rating, a mitigation and a regression test, so that fixes stay fixed.
